# Egg Glass

卵形3Dの柄・ロゴ・照明と、SVG背景のアニメーションをブラウザで編集するツール。

公開URL: https://bats5020.github.io/motion-lab/tools/egg-glass/

## 正本

今後の実装・修正の正本は、このMotion Labリポジトリの `tools/egg-glass/`。FENNEL U19案件で制作したEgg Study v21を2026-09-15に統合。元案件の `egg-study/` は移設時点の控えとして保持。

## 操作

- 上部の「柄・画像」で炎・グラデーション・画像の柄、4色パレット、ロゴ画像の読み込み・位置・サイズ・濃さを調整。
- 照明パネルで光の位置と光沢を調整。ロゴにも卵と同じ陰影・反射がかかります。
- スクロール%ごとに卵の位置・スケール、背景のグラデーション・スケールをキーフレーム設定。卵はプレビュー上でも移動可能。
- W / Hで実際の描画サイズを指定。`@` で編集UIの表示／非表示とプレビュー領域の拡大を切り替え。
- Exportから、指定%のPNG、区間指定の動画（対応ブラウザではMP4、それ以外はWebM）、画像・設定込みの単体HTMLを保存。
- 卵だけ保存する場合：Export → 画像 · PNG → 保存する対象「卵のみ（背景透過）」→ PNGを保存。指定したフレームと出力サイズを使い、柄・ロゴ・照明を含めて保存します。動画・HTMLの出力対象は変わりません。
- 単体HTMLはネット接続不要。`@` で編集を再開し、再書き出しも可能。

## 保存・環境

数値設定はlocalStorage、読み込んだ画像はIndexedDBに保存します。保存内容はブラウザ・公開元のURLごとに独立しており、localhostの設定は公開版へ自動では移りません。読み込んだ画像はサーバーへ送信しません。

WebGL 2対応の現行ブラウザが必要です。動画は実時間で録画するため、解像度・端末性能によってフレームレートが変わります。ローカル開発時はHTTPサーバー経由で開いてください。ビルドは不要です。

`style.css` は手書きのソースです。`html-export.js` は実行モジュールと素材を単体HTMLに梱包するため、新しい依存ファイルを追加した際は梱包リストも更新してください。
