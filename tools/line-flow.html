START WITH A LOOK 01—08

LAYERS

上のレイヤーほど手前に表示。
目のボタンで一時的に非表示。

はじめての使い方

1. 手描きで始めるか、構図を選ぶ
2. 手描きして「整え具合」で流れを整える
3. 配色・質感・動きを調整
4. 画像やHTMLで書き出す

線上をダブルクリックで点を追加。点を選択してDeleteで削除、矢印キーで移動。「手描き」はドラッグで線を追加。「描き直す」は選択中の線を置き換えます。

Space：再生／停止
⌘Z：元に戻す
⌘⇧Z：やり直す

LIVE PREVIEW
プリセットから始めるか、線を追加してください

スライダーで瞬間を選択。PNG・SVGは現在のフレーム、HTMLは動き付きで保存。

ライン 01INSPECTOR
描いた線に近く流れを優先

ドラッグで描いて離すと、自然な曲線に整えます。

交差した線は、終点側が手前に重なります。レイヤーを分けると重なり順を変えられます。

グレインは線の内側だけに適用。透過背景のまま素材として書き出せます。

編集中の設定は、このブラウザに自動保存します。別の端末に移すときはJSONで設定を保存してください。
