# Egg Glass のMotion Lab統合（2026-09-15）

## 決定

ユーザーの「motionlabに追加してほしいのと、公開お願い」により、Egg Study v21を `tools/egg-glass/` として公開。以後の正本はMotion Labの同フォルダ。元案件側は控えとして保持する。

Three.jsとSVGLoaderはMITライセンス込みで同梱。画像処理はブラウザ内で完結する。既存の保存キーは互換性維持のため変更しない。

## 統合差分

- ハブのMotionカテゴリにEgg Glassを追加。
- ホームピル追加。`@` で非表示、書き出しHTMLでは削除。
- 公開ページのタイトルを更新し、プレビュー用noindexを除去。
- 実行に必要なモジュールと提供素材のみ移設。旧PNG背景・内部履歴は含めない。
- ハブ確認時に見つかった既存Effect Stackサムネイルの負の矩形高を0に制限。faviconの不要な404も抑制。

## 公開前検証

2026-09-15、Chrome headless（1440×1000／390×844）、HTTP配信したサブディレクトリで検証。

| 対象 | 結果 |
|---|---|
| ハブ→ツール、ホームへ戻る、@でUIとホームピルを切替 | PASS |
| 640×480、37.5%と100%のPNG | 指定寸法、フレームごとに異なる画像 |
| 1秒動画 | MP4/H.264 640×480 1.046秒、WebM/VP9 640×480 1.065秒（ffprobe確認） |
| 録画中止 | 状態・キーフレームを復元 |
| 単体HTML | 約7.3MB、HTTP通信を遮断して起動・スクロール再生・再書き出し成功 |
| ロゴ | 表面4種、透明度、前面のみ表示、位置／サイズ、画像アップロード、リロード復元、PNG／HTMLへの反映 |
| コンソール | 上記実行中のエラーなし |

Claude Codeによる読み取り専用レビューを実施。静的パス、HTML梱包の依存網羅、ホームピル、画像処理、ハブのエントリを確認し、release blockerなし。保存キーの旧案件名は非機能的な指摘として受領、互換性を優先して維持。

ブラウザ・端末によって動画形式と実フレームレートは変わる。操作説明と保存範囲は [ツールREADME](../tools/egg-glass/README.md) を参照。
