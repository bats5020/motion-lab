# Image Switcher

画像を並べ、ロゴのオープニングや写真のスライドを作るPC向けツール。実装の正本は `tools/image-switcher.html`、ハブの掲載情報は `index.html` の `TOOLS`。Word Switcherから派生した独立ツールで、元のWord Switcherは変更しない。

## 使い方

1. 「画像を追加」でPNG・JPG・WebP・SVGをまとめて選ぶ。初回はサンプル5枚と入れ替わる。以後は末尾へ追加される。
2. 画像をドラッグ、または選択して「前へ／後へ」で並べ替える。チェックを外すと再生から外れる。サムネイルを押すとその画像の表示時刻へ移動する。
3. 「ロゴ OP」「フェード」「スライド」「写真スライド」から選び、1枚の表示時間と画像の大きさを調整する。
4. 再生ボタンまたはスペースキーで確認する。シークバーで切り替え途中も停止できる。
5. 動画、今の瞬間のPNG、画像を内包した単体HTMLに保存する。作品JSONで画像と設定をまとめて持ち出せる。

「OPの開始・終了」で最初・最後の表示時間、縦に開く／閉じる、フェードイン／アウト、最後の画像で止める動作を変更できる。最初・最後の表示時間が0なら通常の表示時間を使用する。繰り返しOFFでは1巡で止まり、往復再生は先頭まで戻って終了する。

中央配置は画像の縦横比を維持。「全体を収める」と「枠いっぱいに切り抜く」を選べる。切り抜き位置は画像ごとにX・Yで調整。背景の透過はPNG・連番PNG・単体HTMLに反映する。動画は指定した背景色で合成する。

## 初期OPと参照

2026-09-16、maoの参照 `https://to2kyo2.com/` のオープニングをブラウザで観察した。中央の同じ位置に置いた図柄を短い間隔でカット切り替えし、最後に縦方向へ閉じる構成を参考にした。参照サイトのコード・ロゴ・画像は実装に含めない。観察用のスクリーンショットと動画は `/private/tmp/to2kyo2-observe/` にのみ置く。

初期値は1600×900、画像の大きさ32%、カット切り替え、開始0.35秒・最初0.9秒・中間各0.22秒・最後0.7秒・終了0.4秒。独自に作成したMOTIONのSVGサンプル5枚で3.01秒となる。起動時は最初の画像を静止表示し、「最初から」でOPを再生する。ロゴそのものの変形ではなく、読み込んだ画像を切り替える方式。

通常の切り替えはカット、フェード、上下左右のスライド、ズーム、フリップ、ブラー、ワイプ。表示時間と切り替え時間は別々に加算する。開始・終了の演出がないループでは、最後から先頭へのトランジションも描画する。

## 実装と出力

- Canvas 2Dの時刻指定レンダラーをプレビュー・静止画・連番・動画・単体HTMLで共用。プレビューは画面に収まるサイズ、出力は指定した解像度で描く。
- フェードは透明な中間バッファへ重み付きで合成し、不透明な画像同士の重なり部分に不要な透明度の落ち込みを作らない。
- 画像をデータURLとして保持し、HTMLとJSONに内包する。画像名はDOMのテキストとして扱い、HTML埋め込み時にはJSON内の `<` をエスケープする。SVGはImage経由で描画し、編集ページのDOMには挿入しない。
- PNG連番ZIPは非圧縮ZIPにPNGを格納。時刻はFPSから固定して計算し、半透明を保持する。
- 動画はMediaRecorderで1巡を実時間録画。対応形式を確認し、WebM（VP9／VP8）またはMP4で保存する。FPSは録画の目標値で、端末負荷による可変フレームレートになり得る。透過が必要な場合はPNG連番／HTMLを使用する。
- 単体HTMLはオフラインで動作し、再生／停止／再再生を備える。`prefers-reduced-motion` では最初の画像を静止表示する。1巡終了時にcanvasから `image-switcher:complete` イベントを送出する。
- 取り消し／やり直しを30段階保持。画像読み込み失敗時には元の作品を保持し、書き出し・キャンセル・録画非対応時には操作を解放して元の表示時刻と再生状態へ戻る。
- 出力サイズ64〜4096px。画像は最大40枚、1枚40MB・2400万画素以内、合計1億画素以内。PNG連番は最大3600枚／400MB。過大な入力でブラウザが動作しなくなることを避けるための上限。

追加のライブラリやビルドは不要。UIは既存の `shared/tokens.css` を使用する。

## 検証

ブラウザ検証:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node tests/image-switcher.browser.cjs
```

ローカルURLは既定で `http://127.0.0.1:8767/tools/image-switcher.html`。変更する場合は `IMAGE_SWITCHER_URL` を指定する。証跡は既定で `/private/tmp/image-switcher-qa/`（`IMAGE_SWITCHER_OUTPUT` で変更可能）。
