# チケットをビジュアルに取り入れたWebサイト

2026-09-13調査。ユーザー支給の3枚のチケット画像を起点に、紙のチケットの形・文字組み・並べ方をWebに展開した事例を探した。参照素材や他サイトのコードはリポジトリに含めない。

## 1. Virgil Abloh Archive / The Codes（2025）

[当時のサイト画面 — Siteinspire](https://www.siteinspire.com/website/13314-virgil-abloh-archive)

横長の水色チケットを大きく置き、イベント名、日時・会場、バーコード、通し番号風の数字を一枚にまとめる。大きなサンセリフと小さな事務的な文字の差、右端の半券、白い余白の使い方が今回の画像に近い。ヒーローの主要情報をチケットとして見せる際の第一候補。

2025年の掲載画像をブラウザで確認。現在の[公式サイト](https://www.virgilabloh.com/)は別の告知デザインに更新されているため、この表現の確認には上のアーカイブを使う。

## 2. Chef’s Breakfast 2025 — BABUSHKA

[制作者によるWebデザイン事例](https://dribbble.com/shots/27709555-Chef-s-Breakfast-2025-Event-Website-Design)

蛍光イエローグリーン、ピンク、オレンジ。画面の上下の連続した切り欠き、左右の大きな切り欠き、ヘッダー下のミシン目を組み合わせ、ページそのものを一枚のチケットにしている。チケットの形をサイト全体のレイアウトへ広げる方法として近い。

制作事例のPC画面を確認。[現行公式サイト](https://bestchefs.ru/)は2026／2027向けの別デザインなので、2025版の参照は制作事例を使う。

## 3. Supabase Launch Week 7（2023）

[公式の制作記事・画面](https://supabase.com/blog/designing-with-ai-midjourney)

紫と金の流体グラデーションをチケットに敷き、右の細い領域に縦向きの通し番号を置く。多数のチケットをずらして敷き詰めた「ticket wall」は、支給された赤黒チケットの反復配置に近い。グラデーションとチケットを組み合わせる参考として有力。

記事内のticket wall画像まで確認。旧イベントのチケット一覧URLは現在404なので、公式記事の「Displaying the images」を参照する。記事には個別チケット生成、共有と金色への変化、一覧の無限スクロールも説明されている。

## 4. All Things Go 2024 — Matthew Lewicki

[制作者のサイト制作事例](https://matthewlewicki.com/work/atg/site/)

「Desktop Ticketing section」を参照。オレンジ系グラデーションとパターンを券種ごとに変え、大きな券種名、料金、特典を縦のカードに分ける。角の小さな切り欠きや罫線でチケットのディテールを残しながら、情報を比較しやすくしている。

PCのチケット画面を確認。グラデーションの色面と太い文字の組み合わせ、複数カードを並べる情報設計の参考。[現行公式サイト](https://allthingsgofestival.com/)は開催年に合わせて更新される。

## 5. Aurel’s Grand Theater

[実サイト](https://aurelienvigne.com/) / [掲載画面・紹介](https://www.commarts.com/project/38662/aurel-s-grand-theater)

劇場を探索する3Dポートフォリオ。黒地と金文字のチケットを、傾けて重ねたビジュアルがある。支給画像のような印刷物の重なりをWebの空間表現へ広げる参考。色や書体の方向は今回と異なる。

実サイトの開始画面と、Communication Arts掲載のチケット画像・紹介内容を確認。劇場内の全操作を検証したわけではない。

## 今回の画像への落とし込み案

一枚を主役にする構成はVirgil Abloh Archive、ページの輪郭に使う方法はChef’s Breakfast、流体グラデーションと反復配置はSupabaseが参考になる。

ヒーローでは横長チケットを2〜3枚重ね、主役の一枚にタイトル・日時・会場をまとめる。右側の半券に参加・申込の導線を置き、後続の情報カードにも同じ罫線や切り欠きを使うと、飾りと情報の見せ方をつなげられる。これは今回の参照画像からの提案であり、各サイトの実装をそのまま説明したものではない。
