# Smearworks — 人物ブラー×片側の色面

2026-10-19。実装の正本は `tools/smearworks.html`（WebGL2、依存ゼロの単体HTML、PC専用）。

## 目的

白黒ポートレートに放射状のブラーと残像をかけ、片側（初期値は右）に色面を入れる。スポーツのラインナップ画像のような1枚を、少ない項目で作る。

## 方針（2026-10-19 整理）

一度、スミア／ストレッチ・各種マスク・サーマル着色・エッジグロー・プリセットまで広げたが、要素が多すぎたため「人物のブラー」と「右側の色の入り方」の2点に絞り直した。広げた版は `add-smearworks` ブランチの履歴（6b30952）に残っている。熱分布グラフィックは [Thermal Flow](../tools/thermal-flow.html) で作る。

## 項目

| 区分 | 項目 | 中身 |
|---|---|---|
| ブラー | 強さ／中心の残し方／残像 | 中心から離れるほど強く流れる放射ブラー（64サンプル、ジッター付き）。中心付近は元のまま残す。残像は中心から拡大したコピー2枚をスクリーンで重ねる |
| 色 | 色／直線・円形／位置・角度（直線）／大きさ・外側に入れる（円形）／境界のぼかし／顔の残り方 | 明るさを色のランプ（暗部は深い色、明部は少し明るい色）に通し、ベタ塗りと混ぜる。「顔の残り方」がランプとベタの比率。境界は直線（角度付き）か円形のなめらかなグラデーション |
| 仕上げ | コントラスト／粒子／枠 | 白黒化はトーン段で行い、コントラストもそこで掛ける |

プレビュー上の操作：ドラッグでブラーの中心を移動。直線は上端の白い点で境界を、円形は中心の点と縁の点で位置と大きさを動かす。スペースキーでBefore。

## 実装メモ

- パス：トーン（白黒・コントラスト、16bitリニア）→ 放射ブラー → 残像 → 色・粒子・枠
- パラメーターは画像幅比・UV基準。プレビュー（長辺1600px、操作中は900px）と書き出し（写真の解像度、長辺最大4096px）が一致する
