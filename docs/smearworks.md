# Smearworks — 人物ブラー×色面（参考ルックの再現）

2026-10-19。実装の正本は `tools/smearworks.html`（WebGL2、依存ゼロの単体HTML、PC専用）。

## 目的

参考ルック（白黒ポートレート、頬を中心に右へ流れる放射ブラーと残像、顔の左側だけ白黒で残して周りを赤い色面）を、写真1枚から作る。文字は入れない。

## 経緯

1. スミア／ストレッチ・各種マスク・サーマル着色・エッジグローまで広げた（6b30952）→ 要素過多
2. 「人物のブラー」と「色の入り方」に絞った（af5773d）
3. 参考ルックをPythonで完全再現し、その処理をそのままWebGLへ移植（本版）。初期値はPython版で参考に合わせた値

## 処理（Python版 make.py と同じ）

| 段 | 内容 |
|---|---|
| 切り抜き | 比率（2:3／4:5／1:1／9:16／元画像）と拡大。プレビューをドラッグで移動、ホイールで拡大 |
| トーン | 白黒化 → コントラスト×明るさ → ガンマ1.15 |
| 放射ブラー | ◎を中心に48サンプル。中心から離れるほど強く、縦は横の (1−横への流れ) 倍だけ流す。中心付近は元のまま |
| 残像 | 中心から 1+0.4×残像 倍に拡大したコピーを、ブラーのかかる範囲だけ混ぜる（目鼻が二重に） |
| 色面 | 点線の楕円の内側を白黒で残し、外側を色面に。単色かグラデーション。グラデーションはThermal FlowのLUT（ストップの硬さ付き）と linear（line）の値の求め方（向き・幅・位置・fbmゆらぎ・ガンマ・コントラスト・オフセット）をそのまま使い、共有URLを貼ると読み込める。直線以外の形のプリセットは「写真の明るさ」基準で適用。暗部でも色のまま、明るい部分だけ白寄りに抜ける |
| 仕上げ | 粒子・枠 |

## 項目

構図（比率・拡大）／ブラー（強さ・横への流れ・中心の残し方・残像）／色面（グラデーション or 単色、グラデーションは向き・色の位置・ゆらぎ・基準（画面の向き／写真の明るさ）、Thermal FlowのURL読み込み、境界のぼかし・明るい部分の抜け）／仕上げ（コントラスト・明るさ・粒子・枠）。楕円とブラーの中心はプレビュー上のハンドルで動かす。
