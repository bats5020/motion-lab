# Smearworks — 写真×スミア×熱分布の融合ツール

2026-10-19。実装の正本は `tools/smearworks.html`（WebGL2、依存ゼロの単体HTML、PC専用）。

## 目的

スポーツ／eSports／音楽KV向けに、白黒ポートレートの片側をスミアで流し、赤い色面や熱分布カラーと融合させた1枚を、スライダーとドラッグ操作だけで作る。

## モード

| モード | 内容 |
|---|---|
| PORTRAIT | トーン → ズームブラー → スミア／ストレッチ → 残像 → ディテール保持 → 色面 → エッジグロー → 質感 |
| HYBRID | PORTRAITの処理に、フロー場由来のマスクと LUT 着色（値＝写真の明るさ×フロー場）を重ねる |

熱分布グラフィック単体（THERMAL）は [Thermal Flow](../tools/thermal-flow.html) で作る。Smearworksでは持たない。

## 決定事項（2026-10-19）

- MOTION LABの単体HTMLとして置く。場・LUTはThermal Flowと共有する方向（共通化は次段）。React化は見た目が固まってから
- THERMAL単体はThermal Flowに寄せる
- 人物セグメンテーションは次段
- PCのみ（スマートフォン対応は対象外）

## 実装メモ

- スミア：56サンプルのトレイル（平均と比較（明）の混合、ジッター付き）＋スリットスキャン型ストレッチ＋ノイズで向きを曲げる。マスクは不透明度ではなく長さを制御
- マスク：全体／楕円／線形／帯／フロー。楕円・線形・帯は「境界のゆらぎ」でフロー場により座標をずらし、有機的な境界にする
- フロー場：異方性FBM＋2段ドメインワープ（スケール・向き・伸び・シード）
- エッジグロー：値としきい値の差を画面上の勾配（dFdx/dFdy）で割ってピクセル距離に近似し、exp減衰で発光
- 中間バッファはRGBA16F。パラメーターは画像幅比・UV基準なので、プレビューと書き出し（長辺最大4096px）が一致する
