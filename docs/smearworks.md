# Smearworks — 人物ブラー×色面（参考ルックの再現）

2026-10-19。実装の正本は `tools/smearworks.html`（WebGL2、依存ゼロの単体HTML、PC専用）。

## 目的

参考ルック（白黒ポートレート、頬を中心に右へ流れる放射ブラーと残像、顔の左側だけ白黒で残して周りを赤い色面）を、写真1枚から作る。文字は入れない。

## 経緯

1. スミア／ストレッチ・各種マスク・サーマル着色・エッジグローまで広げた（6b30952）→ 要素過多
2. 「人物のブラー」と「色の入り方」に絞った（af5773d）
3. 参考ルックをPythonで完全再現し、その処理をそのままWebGLへ移植（本版）。初期値はPython版で参考に合わせた値

## 処理（Python版 make.py と同じ）

| 段 | 内容 |
|---|---|
| 切り抜き | 比率（2:3／4:5／1:1／9:16／元画像）と拡大。プレビューをドラッグで移動、ホイールで拡大 |
| トーン | 白黒化 → コントラスト×明るさ → ガンマ1.15 |
| 放射ブラー | ◎を中心に48サンプル。中心から離れるほど強く、縦は横の (1−横への流れ) 倍だけ流す。中心付近は元のまま |
| 残像 | 中心から 1+0.4×残像 倍に拡大したコピーを、ブラーのかかる範囲だけ混ぜる（目鼻が二重に） |
| 色面 | 点線の楕円の内側を白黒で残し、外側を色面に。単色かグラデーション。グラデーションはThermal FlowのLUT（ストップの硬さ付き）と linear（line）の値の求め方（向き・幅・位置・fbmゆらぎ・ガンマ・コントラスト・オフセット）をそのまま使い、共有URLを貼ると読み込める。直線以外の形のプリセットは「写真の明るさ」基準で適用。暗部でも色のまま、明るい部分だけ白寄りに抜ける |
| 仕上げ | 粒子・枠 |

## 項目

構図（比率・拡大）／ブラー（強さ・横への流れ・中心の残し方・残像）／色面（グラデーション or 単色、グラデーションは向き・色の位置・ゆらぎ・基準（画面の向き／円の中心から／写真の明るさ）、円の中心からは楕円の形に沿って外へ広がる（広がり）、Thermal FlowのURL読み込み、境界のぼかし・明るい部分の抜け）／仕上げ（コントラスト・明るさ・粒子・枠）。楕円とブラーの中心はプレビュー上のハンドルで動かす。

## 組み込みのグラデーション

Thermal Flowの共有URLから取り込んだ色の並び：Thermal Flow プリセット 1（水色・クリーム・赤橙）、ディープティール（黒→紺→ティール→砂→クリーム）、ダークゴールド（黒→茶→金→クリーム）、ほか赤→黒、VALO レッド（濃紺→赤→ペーパー）、VALO ペーパー（ペーパー→赤→濃紺）。流体リボンなど直線以外の形は再現せず、色の並びを写真の明るさで当てる。

2026-10-29：VALO 2色を追加。Thermal Flowの同名プリセットの色・ストップ位置を維持し、既存の滑らかな補間を使用。既存4色の後ろに追加し、初期配色と選択順を維持する。
ローカルChromeで既存4色の描画が公開版と画素単位で一致すること、新規2色の切り替え・3種の基準・PNG保存・プリセットの保存と再読み込み・取り消し／やり直し・初期化を確認。

## プリセット

加工の設定（ブラー・色面・グラデーション・楕円・仕上げ・比率）に名前をつけてブラウザ（localStorage）に保存する。写真ごとに変わる拡大・位置は保存しない。同じ名前は上書き保存。削除は2回押しで確定。保存した一覧はJSONで書き出し・読み込みでき、別のブラウザやPCへ移せる（同名は上書き）。

## 書き出し

PNG。長辺は切り抜いた範囲に合わせて2000〜4096px（小さい切り抜きは2000pxまで拡大）。
