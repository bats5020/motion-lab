# U19 Vortex — 設計メモ

蓋絵・待機画面の下に敷く「中心へ吸い込まれていく渦」のループ背景。MSI 2024 決勝配信の背景（サーモ配色の腕が暗い中心へ巻き込まれる）の動きを、U19 の配色で作るためのツール。

## なぜ Thermal Flow と別にしたか

Thermal Flow の渦ピンは模様をその場でねじるだけで、モーションも模様がその場で揺らぐ動きになる。「中心へ流れ込み続ける」動きは作れないため、同じ LUT を使う専用ツールにした。

## 描き方

- 画面を対数極座標（角度 × log 半径）に開き、そこに周期つきノイズ（fbm 2段ワープ）を置く。
- 角度方向は「腕の数」で周期にしてあるので、一周したところで継ぎ目が出ない。
- 巻きの強さ = 角度に log 半径を足す量。マイナスで逆巻き。
- 吸い込み = log 半径方向へノイズをずらす。ループ1周で周期ちょうど（整数回）ずらすので、最後のコマが最初に戻る。回転も同じく整数回。
- フルレンジ：縮小パスで場の明暗を実測し、1〜99%点を 0〜1 に引き伸ばしてから LUT を引く。どの設定でも黒〜青〜クリーム〜朱〜黄の全色が出る（Thermal Flow のフルレンジと同じ考え方）。
- 配色は U19 ミラーの黒寄り（B-Spline・OKLab、両端の色を重ねて段差なし）。

## 初期値

2026-11-02 に mao がこのツールの試作版で書き出した 15 秒ループの見え方に合わせてある（腕3・巻き1.1・細かさ0.5・うねり0.7／0.35・2段・シード12・外周の明るさ1.0）。

## 書き出し

- MP4：1920×1080・30fps・H.264。WebCodecs で 1 コマずつ描いてエンコードするので、PC が重くてもコマ落ちしない。ループ回数（1／2／4）で尺を伸ばせる。MP4 の書き出し処理は U19 HUD Sequence / Tile Scroll と同じ。
- WebCodecs が使えないブラウザでは MediaRecorder の実時間録画（MP4 か WebM）に切り替わる。
- PNG：現在のコマ。
- 設定は URL のハッシュに入る（「設定URLをコピー」）。

## カクつき対策（2026-11-03）

- 書き出しのコマは `new VideoFrame(canvas)` ではなく、画面外のバッファに描いて `readPixels` で読んだピクセルから作る。キャンバスのスナップショットだと GPU によって前のコマが重複して入り、保存した動画がカクつくことがあるため。プレビューの表示は書き出し中も変わらない。
- 粒子は初期値で止めた（「粒子をコマごとに動かす」でオン）。コマごとに変わる粒子は情報量が多く、2秒ごとのキーフレームで画質が上下して周期的なちらつきに見えるため。
- ビットレートを約 37Mbps（1920×1080・30fps）に上げた。

## 確認したこと（2026-11-02）

- 2 秒ループの MP4 を書き出し、60 フレーム・30fps・H.264 を ffprobe で確認。最終コマ→先頭コマの差分が隣接コマ同士の差分と同じ大きさで、継ぎ目がないこと。
- 共通の書き出しダイアログ（export-workbench）が開き、ページエラーがないこと。
