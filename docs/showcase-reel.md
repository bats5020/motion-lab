# Showcase Reel — 設計メモ

`tools/showcase-reel.html`。静止画のデザインや短い映像を3Dのカードに並べ、ループするショーケース動画にするツール。

## 出発点

- 参考: orelin.app（ブラウザ内で「テンプレートを選ぶ → 素材を入れて調整 → 書き出す」流れのアニメーション／ショーリール作成サービス）。
- 参照したのは公開ページに書かれた**体験の流れと機能の範囲**だけ。エディタ本体（orelin.app/editor）はこの作業環境から開けなかったため、テンプレートの見た目・パラメータ名・UIは独自に設計した。
- ソースコード、ロゴ、画像、フォント、文言は一切使っていない。名前・テンプレート・スタイル・サンプル素材はすべてオリジナル。UIは MOTION LAB の workbench（`shared/workbench.css` / `motion-workbench.css` / `export-workbench.js`）に揃えた。

| 参考サービスの機能（公開ページ記載） | Showcase Reel での対応 |
|---|---|
| テンプレートを選び、スタイルを合わせる | テンプレート9種 × スタイル6種（下記） |
| 画像・動画・デザインを追加 | PNG/JPG/WebP/SVG/MP4/WebM、複数・ドロップ・並べ替え |
| パラメータを細かく調整 | レイアウト／カメラ／カード／影／背景／テキスト／仕上げ |
| 高品質で書き出し、任意の比率・1080p〜4K | MP4（H.264）・PNG・PNG連番ZIP、720p〜4K、6比率、24/30/60fps |
| 素材はブラウザ内で処理しサーバーに送らない | 同じ（外部通信なし） |

## テンプレート

| キー | 名前 | 動き | ループの継ぎ目 |
|---|---|---|---|
| wall | タイルウォール | 傾けた面に敷き詰め、列ごとに逆走 | 1ループで「素材の周期 P 枚 × 速さ」ちょうど進む |
| marquee | マーキー | 横帯を数段、交互に流す | 同上 |
| cascade | カスケード | 縦列が1×／2×の速さで落ちる | 同上（速さは整数倍） |
| carousel | リング | 円環を回転 | 1ループで素材数ぶんの角度だけ回る |
| tunnel | フライスルー | 奥から手前へ飛んでくる | 各カードが奥行きを整数回往復 |
| deck | デッキ | 一番上を後ろへ送る | ループ長 = 素材数 × 1枚の時間 |
| focus | フォーカス | 中央1枚＋左右に控え、カバーフロー式に送る | 同上 |
| spread | 展開 | 束 → グリッド → 束 | 開閉が1ループ内に収まる |
| fan | ファン | 扇状に並べ、1枚ずつ持ち上げる | 波が整数周 |

最初と最後のフレームは一致する（ブラウザで全テンプレの t=0 と t=L 直前を画像比較して確認）。リング／デッキ／フォーカス／ファンは16:9基準で組んでいるので、正方形・縦長の比率では自動で縮めて画面に収める。

## 描画

- WebGL2 1枚。背景（単色／線形／円形グラデ＋ドット／グリッド）→ カード（影 → 本体、奥から順に描く）→ テキスト → 周辺減光・グレイン。
- 座標は「画面の短辺 = 1000」。プレビューと4K書き出しで見た目（角丸・影・余白）が変わらない。
- カードは角丸SDF。素材は枠に合わせてカバー切り抜き。フレームは「なし／ブラウザ／スマートフォン」をシェーダーで描く（画像素材は不要）。
- 画像はミップマップ＋異方性フィルタ（傾けた面でもちらつかない）。動画はフレームごとにテクスチャ更新。
- カメラは傾きX/Y・回転Z・ズーム・画角・ゆらぎ（ループに同期した周期的な揺れ）・奥のフェード。プレビュー上のドラッグで傾き、ホイールでズーム、ダブルクリックでテンプレの初期値に戻る。

## 書き出し

- MP4: 別キャンバスでコマ送りに描画 → WebCodecs（H.264）→ 他のモーション系ツールと同じ MP4 ボックス書き出し。動画素材は各フレームの時刻へシークしてから描く。WebCodecs が無いブラウザは MediaRecorder（WebM）でリアルタイム録画。
- モーションブラー: 書き出し時だけ、1フレーム内を4／8サンプルで平均（シャッター180°相当）。
- PNG（今のフレーム）、PNG連番（無圧縮ZIP、最大1800枚）。
- 共通の書き出しダイアログ（`shared/export-workbench.js`）に登録済み。透過は非対応（背景込み）。
- 設定はブラウザに自動保存し、JSONで保存・読み込みもできる（素材は含まない）。元に戻す／やり直す（⌘Z / ⇧⌘Z）あり。

## 確認したこと（2026-10-31・ヘッドレス Chromium / SwiftShader）

- 全9テンプレの表示、各テンプレのループ継ぎ目（最初と最後のフレームが一致）
- 画像＋動画（MP4）素材の追加、ブラウザ／スマホフレーム、テキスト、スタイル切り替え、元に戻す
- MP4書き出し: 1280×720・24fps・72フレーム、720×1280（動画素材入り）を ffprobe／ffmpeg で再生確認
- 390px幅のスマホ表示
- `node tests/showcase-reel.browser.cjs`（全テンプレの継ぎ目＋動画書き出し）、`node --test tests/*.test.cjs`（smearworks の既存の失敗1件を除き通過）、`node tests/catalog.browser.cjs`

実機（Mac の Chrome / Safari）での見た目・書き出し速度、4Kの書き出しはまだ見ていない。

## ブラッシュアップ（2026-11-01）

「洗練感が足りない」というレビューを受けて、見た目の質を上げた。

- 光と艶: カードの向きに応じた陰影、向きに合わせて滑るハイライトの帯、上辺が明るく下辺が沈む縁の光（`仕上げ › 光と艶`）
- 影を2層に: 広く淡い環境影と、近くて濃い接地影
- 被写界深度: 焦点面（シーンの中心）から離れたカードほど、縁をやわらげて素材をぼかす。テンプレートごとに初期値を持つ（`仕上げ › 被写界深度`）
- 背景に「グロー（光だまり）」を追加し、スタイル6種の配色を抑えめに作り直した
- グレインを乗算のフィルム粒子にした（黒が浮かない）
- サンプル素材をUI・エディトリアル・映画ポスター・ブランドシステムなどの落ち着いた6点に差し替えた
- デッキは後ろのカードが上に覗く重ね方に、リングは大きめの初期構図に変更
