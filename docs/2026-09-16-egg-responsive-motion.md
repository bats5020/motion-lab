# PC / SP別のアニメーション（2026-09-16）

画面幅により移動方向を変えたいという依頼に対応。判定はユーザー指定の画面幅基準。初期境界は768px（未満がSP、以上がPC）、編集画面の幅や表示倍率ではなくプレビューの描画幅を使う。

## 設定・操作

アニメーションパネルの「PC / SPで動きを分ける」で有効化。初回は現時点のPC設定をSPへ複製し、卵の位置・スケール・各キーの時点／補間、背景のキー・余白・合わせ方を独立して保存。「PCで確認」「SPで確認」は判定に合う描画サイズへ変更する。W / Hからも編集可能。無効化するとPC側を共通で使用し、SP側の値は保持する。

設定形式はv4。ルートのキーと背景はPC／共通として旧構造を維持し、responsiveにenabled・breakpoint・spを保持。旧URL・v1〜v3保存はPC／共通の値を保持し、分岐を無効のまま移行する。履歴は両設定のスナップショット。URLとlocalStorageにも両方を保存する。

PNG・動画は現在の描画幅に合う設定を固定して書き出す。レスポンシブが有効なHTMLではviewportをwindowへ変更し、実際の表示先の幅に追従させる。無効時のHTMLは従来どおり指定寸法を維持。

## 確認

ユーザー提供のv3設定（PC終点X=-20.2%、スケール88.8%、背景終点163.6%）を読み込んで保持を確認。SPのみX=0・Y=-24%・スケール70%へ変更してもPCに影響なし。背景の独立、キー追加／時点変更、Undo／Redo、767px／768pxの境界、境界値編集、無効／再有効、保存・URL復元をChromeで確認。固定1440pxプレビューは編集画面を390pxへ縮小してもPCを維持。

SP寸法のPNG、オフライン単体HTMLの1200px→390pxによるPC/SP切替と実際の移動方向を確認。従来キーフレームのドラッグ・移動ハンドル・補間・スクロール・旧形式移行・スマホ操作、通常PNG／動画／オフラインHTML書き出しも確認。
