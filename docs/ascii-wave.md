# ASCII Wave — 文字・絵文字の波

実装の正本は `tools/ascii-wave.html`。処理はブラウザ内で完結する。

## 文字と絵文字

右側の「文字」→「文字セット」に、好きな文字や絵文字を入力する。`🎃` のように1文字だけでも使える。複数の文字・絵文字を並べたセットや、空白を含むセットも使用できる。

1文字だけの場合は空白の段階を補い、その文字で波と余白を描く。絵文字は端末の絵文字フォントの色で表示する。文字色・アクセント色は通常の文字に適用する。

肌色付き・国旗・家族・キーキャップなどは `Intl.Segmenter` で1つの見た目単位にまとめる。これを持たない古いブラウザでは従来のコードポイント分割に戻るため、結合した絵文字の対応には現行ブラウザを使用する。表示できる絵文字とデザインは端末のフォントによる。
