# Flame Transition

`tools/flame-transition.html` — サーモカラーの炎が画面を覆いきった瞬間にシーンAからBへ切り替えるトランジション。

## 参照

MSI 2024 Event Trailer（League of Legends）の、炎が渦を巻いて中央に集まりロゴへ切り替わるカット（約1.2秒、炎が閉じるまで約0.5秒）をWebGLで再現したもの。ロゴ・映像はオリジナルのサンプルに置き換えている。

## 仕組み

- 1枚のフラグメントシェーダーで、進行 `t`（0〜1）と切替点 `cut` から描画する。`t < cut` はAに炎が迫る区間、`t ≥ cut` はBから炎が引く区間。
- 炎の形は「進む向きの座標 g」と「炎の腕（sin）＋simplexノイズ」で作る距離場。g は入り方ごとに変える。
  - 中央へ渦：g = −r（対数螺旋の座標で腕をねじる）
  - 外へ広がる：g = r
  - 一方向：g = 進行方向への射影
  - 両側から：g = −|進行方向への射影|
- 色は距離場の深さとスパイラル方向のストリークを熱量として、プリセットのグラデーション（最大8色）に通す。縁はグラデーションの冷たい端の色。
- 炎の手前（A）と通過後（B）は、熱のゆらぎ（UVディストーション）と輝度のサーモ色化をかけ、Bは時間とともに元の色に戻る。
- 背景（A・B）のねじれ・押し出し・ズーム・熱のゆらぎは「背景の歪み」（0〜100%）でまとめて調整する。初期値は0%で背景は歪まない。サーモ色化は歪みとは別でそのまま残る。

## 消え方

| 設定 | 動き |
|---|---|
| その場で燃え尽きる | 炎が最後に届いた場所から穴が開き、炎は赤から紫へ冷えて消える |
| そのまま抜ける | 炎が同じ向きに進み続けて画面外へ出る（渦は中心に吸い込まれる） |
| シーンB＝映像・写真 | 炎の跡だけ熱でゆらぎ、サーモ色から元の映像へ冷める。残り火・煙は出さない |
| シーンB＝ロゴ（黒背景） | ロゴの明るい部分に残り火、黒地に煙を残す（参照動画の終わり方） |

## 書き出し

A静止0.7s → トランジション（1.25s ÷ 速度）→ B静止1.1s を、比率ごとの出力サイズ（16:9は1920×1080、9:16は1080×1920、1:1は1080×1080、4:5は1080×1350）で録画する。H.264のMP4を優先し、使えないブラウザではWebM。録画中は実時間で進むため、GPUが遅い環境ではコマ落ちする。
