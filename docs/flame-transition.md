# Flame Transition

`tools/flame-transition.html` — サーモカラーの炎が画面を覆いきった瞬間にシーンAからBへ切り替えるトランジション。UIと書き出しは Heatmap Blur に合わせている。

## 参照

MSI 2024 Event Trailer（League of Legends）の、炎が渦を巻いて中央に集まりロゴへ切り替わるカット（約1.2秒、炎が閉じるまで約0.5秒）をWebGLで再現したもの。ロゴ・映像はオリジナルのサンプルに置き換えている。

## 画面

- 下の再生バー：再生／タイムコード（30fps）／タイムライン（A・炎が覆う・炎が引く・B の区間と切替点）。目盛りをドラッグで時間移動、Shift で切替点に吸着。右の |◂ は先頭、CUT は切替点、⟲ はループ。
- 右のパネル：01 シーン／02 タイミング／03 方向／04 炎／05 カラー／06 グレイン／07 書き出し。
- 設定はブラウザに保存され、「初期設定に戻す」で戻る。⌘Z／⌘⇧Z で取り消し・やり直し。
- ショートカット：Space 再生／Home・End／PageUp・PageDown（⌘←→）1コマ（Shift で10コマ）／C 切替点へ／L ループ。

## 仕組み

- 1枚のフラグメントシェーダーで、進行 `t`（0〜1）と切替点 `cut` から描画する。`t < cut` はAに炎が迫る区間、`t ≥ cut` はBから炎が引く区間。
- 炎の形は「進む向きの座標 g」と「炎の腕（sin）＋simplexノイズ」で作る距離場。g は入り方ごとに変える。
  - 中央へ渦：g = −r（対数螺旋の座標で腕をねじる）
  - 外へ広がる：g = r
  - 一方向：g = 進行方向への射影
  - 両側から：g = −|進行方向への射影|
- 色は距離場の深さとスパイラル方向のストリークを熱さとして、露出・ガンマ・位相をかけてから配色（最大16色）に通す。縁は配色の冷たい端の色。
- 色プリセット：Thermal（参照動画）、Thermal Flow、U19／U19 ミラー／U19 アイス（Heatmap Blurと同じ値）。U19系は冷たい端が黒なので、縁が見えるよう先頭の黒い区間を飛ばして使う（`lo`）。
- 背景（A・B）のねじれ・押し出し・ズーム・熱のゆらぎは「背景の歪み」（0〜100%）でまとめて調整する。初期値は0%で背景は歪まない。炎のそばのサーモ色化は歪みとは別でそのまま残る。
- 炎の模様の流れは進行に対して一定なので、トランジションの長さを変えても見え方は同じ（速さだけ変わる）。

## タイミングと動画

- 全体の長さ＝Aの長さ＋トランジション＋Bの長さ。切替点はトランジションの中の割合。
- シーンに動画を入れた場合、Aは先頭から、Bは切替点から再生する。書き出しでは各コマごとに動画を正確にシークする。

## 消え方

| 設定 | 動き |
|---|---|
| その場で燃え尽きる | 炎が最後に届いた場所から穴が開き、炎は赤から紫へ冷えて消える |
| そのまま抜ける | 炎が同じ向きに進み続けて画面外へ出る（渦は中心に吸い込まれる） |
| シーンB＝映像・写真 | 炎の跡だけ熱でゆらぎ、サーモ色から元の映像へ冷める。残り火・煙は出さない |
| シーンB＝ロゴ（黒背景） | ロゴの明るい部分に残り火、黒地に煙を残す（参照動画の終わり方） |

「04 炎 › 切り替え後」で、炎が引く時間（30〜200%）、残り火・煙の量（0〜100%、映像のときは炎の跡のサーモ色の濃さ）、残る長さ（0〜100%）を調整できる。初期値は 100%／50%／50%。

## 書き出し

- 30fpsで1コマずつ描いて書き出すので、重い環境でもコマ落ちしない。
- ロスレスMOV（PNG）：透過対応。「炎だけ（透過）」にするとシーンなしの炎レイヤーをAEで重ねられる。
- MP4（H.264, WebCodecs）：透過なし。「炎だけ」のときは黒地に炎（スクリーン合成用）。WebCodecs が使えないブラウザは MediaRecorder（MP4／WebM）で1コマずつ録画。
- PNG：今のコマ。サイズは 1920×1080／4K／1:1／4:5／9:16。
