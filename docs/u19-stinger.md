# U19 Stinger — 設計メモ

配信の画面切り替え用スティンガー（要件：1920×1080・MOV・3秒ほど・HPのような感じ）。蓋絵の背景で流れている U19 Vortex の渦が、そのまま画面を覆って場面が変わるようにした。

## 動き（初期値・3秒）

- 0〜0.85秒：画面の外から渦の腕が巻き込みながら入り、映像Aを覆う（イーズアウト）
- 覆われている間も渦は中心へ吸い込まれ続ける（吸い込み2回）
- 1.4〜2.9秒：回転を速めながら縮んで中心へ消え、映像Bが出る（イーズイン）

## 描き方

- 渦本体は U19 Vortex と同じ（対数極座標＋周期ノイズ、U19 ミラー黒寄り、フルレンジ）。
- マスクは画面中心からの距離に、渦の腕に沿ったギザ（ノイズ＋巻きのサイン波）を足したもの。外縁 `rout`／内縁 `rin` を時間で動かす。縁にだけ黄色の光を足す。
- 抜けでは渦全体を縮め（ズーム）、回転を加速させる。

## トランジションポイント

設定が変わるたびに、縮小バッファ（192×108）で全コマのアルファを読み、画面が完全に覆われている区間を実測する。その中央をトランジションポイントとして表示し、MOV のファイル名にも入れる。覆いきれない設定のときは警告を出す。

## 書き出し

- 透過MOV：PNG コーデックのロスレス MOV（Flame Transition／Thermal Flow と同じ書き出し方式）。OBS のスティンガー、AE、Premiere でそのまま使える。3秒で約100MB。
- MP4：プレビュー背景（サンプル A→B、チェッカーのときは黒）と合成した確認用。WebCodecs で 1 コマずつ、合成済みのピクセルから作る。
- PNG：現在のコマ（透過）。
- ロゴ（任意）：覆われている間に中央に出す。設定URLには入らない。

## 確認したこと（2026-11-03）

- 初期値で覆われている区間 0.50〜1.67秒、トランジションポイント 1100ms。
- 透過MOV：90コマ・30fps・PNG（RGBA）。6コマ目は画面の43%が不透明、33コマ目は100%、70コマ目は25%。
- 共通の書き出しダイアログから書き出せること、ページエラーがないこと。
