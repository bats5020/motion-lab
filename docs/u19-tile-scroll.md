# U19 Tile Scroll

`tools/u19-tile-scroll.html` — Figma「HUD」フレーム（985:5999）の組みで流れる U19 ロゴタイルの帯が、シーンAを覆い、抜けながらシーンBへつなぐトランジション。UIと書き出しは Heatmap Blur / Flame Transition に合わせている。

## 参照

- タイルの組み：Figma `U19eスポーツ選手権2026` の HUD フレーム。15°回転、ブロック幅445・列ピッチ475.5、列内は文字ブロック→ロゴの繰り返し（424で一周）、隣の列は −94 ずらし。配色は #FF2B12／黒が初期値。
- 入り方：MSI 2024 Format Explainer の、サーモ色の液体が流れ込んでタイルに切り替わるカット。

## 画面

- 下の再生バー：タイムコード、区間（A／帯が入る／タイル／帯が抜ける／B と CUT 位置）、スピードカーブとキーの段（上段＝反転のキー□、下段＝流れのキー◆）。
- 右のパネル：01 シーン／02 タイミング／03 つなぎ方／04 スピード・キーフレーム／05 カラー／06 カラー反転／07 角度・配置／08 モーションブラー／09 書き出し／10 設定。
- ショートカット：Space 再生／J・K 前後のキー／⌥K 流れのキー／I 反転のキー／Delete 選んだキーを削除／F9 イーズ／C CUT／L ループ／PageUp・PageDown（⌘←→）1コマ（Shift で10コマ）。

## 仕組み

- タイルは 951×424（Figma px）の周期を3倍解像度でアトラス化し、シェーダーで回転・スクロール・モーションブラー（シャッター角）をかける。
- つなぎ方
  - サーモ（初期値）：各ピクセルが「暖かい熱 → 透ける赤 → 赤 → にじんだタイル → くっきり」の段階を、進む向き（初期値は右下→左上）＋ノイズで決まる自分の時刻に進む。フチのサーモ（黒→紫→白→オレンジ）は開始角から対角へ、紙に火が移るように角ですぐ点いて加速しながら回り、同じ順で冷める。熱の色は配色LUT（Heatmap Blur と同じ13種＋MSI 2024）。
  - ブロック／列ごと／直線：タイルの区切り・列・直線で切り替わるワイプ。
- 流れ：巡航スピード＋入り／抜けの勢い（現れる瞬間が最速で巡航に落ち着く）＋「流れの位置」キーの補間（イーズ／リニア／停止）。反転は反転キーで切り替わる。キーは「キーを自動で打つ」の設定から生成でき、手で動かす・消す・足すと手動扱いになる。

## 書き出し

- 1コマずつ描いて書き出すので、重い環境でもコマ落ちしない。範囲は全体／トランジションのみ。
- 「タイルだけ（透過）」で、帯とフチの熱だけの透過レイヤーになる（AEでシーンの間に重ねる用）。
- ボタンの並びと形式は Heatmap Blur と同じ。ロスレスMOV（PNG・透過対応）／● 動画を書き出す（MP4 H.264・WebCodecs。使えないブラウザでは MediaRecorder で MP4／WebM を1コマずつ録画）／連番PNG（ZIP・透過対応）／PNG（今のコマ）。
- Claude の Artifact 上で開いた場合は保存に確認が入り、自前で作った MOV は保存できない仕様のため MOV ボタンを隠している（MOTION LAB 版では使える）。
