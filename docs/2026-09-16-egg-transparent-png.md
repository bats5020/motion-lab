# 卵のみの透過PNG（2026-09-16）

ユーザーの「卵だけダウンロードできないかな」に対応。ExportのPNG欄に「卵のみ（背景透過）」を追加。既定値の「卵＋背景」、動画、HTMLの描画対象は維持。

背景色とSVG背景はPNGの描画中だけ除去し、環境照明は維持する。PNGには卵の柄・ロゴ・照明を含め、指定フレームの配置・寸法を使う。ガラスの屈折先に背景が残らないよう、SVG背景はシーン内でも非表示にする。

半透明ガラスのRGBを正しく受け渡すため、PNG描画中は材質のpremultipliedAlphaをWebGLコンテキストに合わせる。背景・クリア色／アルファ・材質の設定はfinallyで復元。

検証：Chrome、640×480、模様ガラス／クリア／淡色／塗装のすべてで四隅alpha=0かつ卵領域のピクセルあり。通常PNGは全画素alpha=255。フレーム0%と75%の差、元の背景表示状態、材質・環境マップ・キー設定の保持、強制描画エラー後の復元と再保存、390×844の操作UIを確認。通常出力とオフラインHTMLからの透過PNGも検証。Claude Code読み取り専用レビュー対象：透過処理・状態復元・アルファ方式の整合。

## 追加：卵の周囲を自動トリミング

「卵だけの場合はトリミングしたい」に対応。卵のみPNGではalphaが0でない全ピクセルの境界まで余白を取り除く。色・アルファ・解像度は変えず、保存ファイル名と完了表示に実寸を反映。卵が描画範囲にない場合は空画像を出力せず、位置・スケール・フレームの変更を案内する。背景込みPNGは従来どおり。

Chrome実機検証：640×480の描画から4材質とも240×305へ自動トリミング。元画像の該当範囲との比較でRGBAの差は0。背景込みは640×480を維持。スケール変更への追従、画面外エラーと状態復元を確認。Claude Codeの限定レビューで阻害事項なし。
